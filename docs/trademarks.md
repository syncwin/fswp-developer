# Trademarks and naming

The product name is "Full-Stack WP DevOps". It uses the abbreviation "WP" instead of "WordPress" in the name.

What the WordPress Foundation's trademark policy says (fetched 2026-09-28 from wordpressfoundation.org/trademark-policy/):

- Businesses may use the WordPress name to describe what they do, but may not use it as part of a product, project, service, domain, or company name, and must not suggest affiliation or endorsement.
- The policy also says not to use "WP" in a way that confuses people. Using "WP" is therefore not automatically safe; it depends on whether the name could be mistaken for an official or affiliated offering.
- "WP-CLI" is a word mark owned by the Foundation. Skill and product names here avoid it and mention the tool only descriptively.

Practices in this project: the plugin name stays focused on its function ("Full-Stack WP DevOps"), with SyncWin identified separately as the publisher in metadata (`plugin.json` author, `marketplace.json` owner) rather than in the visible name; the README and CREDITS state non-affiliation; descriptions use "WordPress" only to describe compatibility; no WordPress logos are used. This is a good-faith reading, not legal advice. Have counsel confirm before a paid or widely promoted launch, and re-read the policy when it changes.
