# Trac ticket comment (draft for the user to post)

**What this patch does**
One or two sentences.

**Why**
The defect or gap, with the ticket's reproduction steps.

**How I tested**
- Environment: WordPress trunk (revision or date), PHP version, database.
- Automated: which PHPUnit tests were added or run, and the command.
- Manual: numbered steps a tester can repeat.

**Backward compatibility**
Anything public that changes, and the deprecation path if so. "None" if none.

**Open questions**
Anything a committer or component maintainer should decide.
